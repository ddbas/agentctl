Usage: agentctl agent clear [options]

Whole-session cleanup for the current agent pane.

Removes the status file and any other per-agent artifacts recorded for the pane.
Exits 0 silently when `$TMUX_PANE` is not set and `--pane` is not supplied, or
when no state file exists for the pane.

Options:
